# C++ Programming — Level 1: 50 Problem Solutions

A complete collection of beginner-level C++ problem solutions from the **Programming Advices** course by **Mohamed Abu Hadhoud**.

## Repository Structure

- `Solution_01` through `Solution_50`: numbered solutions to 50 programming problems.
- `AboHadhoud_All_Lessons.sln`: Visual Studio solution containing the projects.
- `.gitignore`: excludes Visual Studio settings and compiled/build artifacts.

## Requirements

- Visual Studio 2019 or newer
- C++ Desktop Development workload

## How to Run

1. Open `AboHadhoud_All_Lessons.sln` in Visual Studio.
2. Select the desired solution project as the startup project.
3. Press `F5` to build and run.

## Topics Covered

Input and output, conditions, loops, functions, arithmetic operations, grade calculation, factorial and exponentiation, prime numbers, time conversion, and more.
